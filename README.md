# Lab RISC-V ASM — Вариант 4

## Задание
Двумерный массив 5×6. Найти количество положительных и отрицательных
элементов. Обработку массива оформить отдельной функцией.

## Алгоритм
Двойной цикл по строкам и столбцам. Если x > 0 — pos++, если x < 0 — neg++.
Нули не учитываются.

## Си
Файл `lab1.c`. Функция `count(arr, n, m, &pos, &neg)`.

Сборка под RISC-V:
```bash
riscv64-unknown-elf-gcc -march=rv32i -mabi=ilp32 lab1.c -o lab1.elf
riscv64-unknown-elf-objdump -D lab1.elf > lab1.dump
```

## Ассемблер
Файл `lab1.S`. Функция `count` принимает a0 = адрес массива, a1 = N, a2 = M,
возвращает a0 = pos, a1 = neg. Аргументы и возврат — по ABI.
Адрес `arr[i][j] = base + (i*M + j)*4`.

## Результат
```
Positive: 15
Negative: 15
```
